the "dld_networks" folder and manage.py are all that is needed to run the data storage and cleaning backend website, all of the pavlovia experiments send data to
this website (previously hosted on pythonanywhere, no longer active) when participants are finished

the "dld_networks_analysis" folder contains all scored data from our RAs and the script for cleaning and combining all of these scored files. Contains the final, cleaned
files that were used for later analysis, and "analysis_script_clean.py" that can be used to generate the final datasets again
